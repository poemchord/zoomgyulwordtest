# 줌귤 영어 어휘 테스트

GitHub Pages 정적 웹앱입니다. 저장소 루트에 `index.html`을 업로드하고 GitHub Pages를 `main` 브랜치의 `/ (root)`로 설정하면 됩니다.

## 포함 기능
- 15~21주차 영어 어휘 뜻 테스트 및 예문 테스트
- 예문 전체 265개 중 랜덤 30문항
- Enter 키 정답 확인 및 다음 문제 진행
- 문제별 북마크 저장 및 북마크 플래시카드
- 플래시카드 터치/클릭 뒤집기
- 북마크는 브라우저의 localStorage에 저장됩니다. 브라우저/기기 간 자동 동기화는 되지 않습니다.

북마크의 한국어 뜻은 제공된 원본 어휘 PDF의 표기를 그대로 사용합니다.
