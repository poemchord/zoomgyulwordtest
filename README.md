# 줌귤 영어 어휘 테스트

- 기본 테스트: 한국어 뜻을 보고 영단어 입력
- 예문 테스트: 영어 예문 빈칸과 번역을 보고 영단어 입력
- 주차별 전체 출제 / 전체 범위 출제
- 직접 주차 선택: 15~21주차 중 여러 주차를 골라 선택한 주차 단어만 무작위 순서로 전체 출제
- 예문 테스트 전용 전체 랜덤 30개
- 북마크 및 플래시 카드 복습
