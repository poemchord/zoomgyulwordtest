# 줌귤 영어 어휘 테스트

GitHub Pages에 배포할 수 있는 정적 영어 어휘 학습 웹앱입니다.

## 기능
- 기본 테스트: 한국어 뜻을 보고 영단어 입력
- 예문 테스트: 영어 예문의 빈칸, 한국어 번역, 정답 첫 글자를 보고 영단어 입력
- 주차별 전체 단어 및 15~21주차 전체 테스트
- 예문 테스트 전용 전체 265개 중 무작위 30개 출제
- 정답 자동 채점, 오답 목록, 오답 다시 풀기
- Enter 키로 정답 확인 및 다음 문제 진행

## GitHub Pages 배포
저장소 Settings → Pages → Source `Deploy from a branch` → Branch `main` → Folder `/ (root)`로 설정합니다.
