# 줌귤 (Zoomgyul) 영어 어휘 테스트

GitHub Pages에 배포할 수 있는 정적 웹페이지입니다.

## GitHub Pages로 공개하기
1. GitHub에 로그인하고 새 Repository를 만듭니다. 예: `zoomgyul`
2. Repository를 Public으로 설정합니다.
3. 이 폴더의 `index.html`과 `README.md`를 Repository 최상위(root)에 업로드합니다.
4. Repository의 **Settings → Pages**로 이동합니다.
5. **Build and deployment**에서 Source를 **Deploy from a branch**로 설정합니다.
6. Branch는 `main`, Folder는 `/ (root)`로 선택하고 Save를 누릅니다.
7. 몇 분 후 Pages 화면에 공개 주소가 표시됩니다. 보통 `https://사용자이름.github.io/zoomgyul/` 형태입니다.

이 프로젝트는 별도 빌드 과정이나 서버가 필요 없는 정적 HTML입니다.
